# There Is No Sin ✨

*A terminal-based philosophical narrative game.*  
In a world yet untouched by sin, you are the first entity to possess free will. Through moral and ethical choices, you shape the foundation of civilization — will the world remain pure, or gradually descend into corruption?

---

## 🌟 Features
- 🌱 **Text-based ethical and moral simulation**  
- 🎭 **Decisions that shape the outcome of the story**
- 🔄 **Story written in an easily editable JSON format**  
- 🔀 **Randomized elements for replayability**  
- 💬 **Philosophical quotes to guide your journey**

---

## 🛠️ Requirements

Make sure you have the following installed on your system:

- **Python 3.x**: Required to run the game  
- **pip**: Python package manager for installing dependencies

---

## 🚀 How to Clone and Run the Game

### 1. Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/aguswerdhi/there-is-no-sin.git
cd there-is-no-sin
```
### 2. Running Games

After installing the dependencies, run the game with the following command in the terminal:

```bash
python3 game.py
