# There Is No Sin ✨

*A terminal-based philosophical narrative game.*  
**Dalam dunia yang belum ternoda, kamu adalah entitas pertama yang memiliki kehendak. Lewat pilihan-pilihan etis, kamu membentuk fondasi dari peradaban — apakah dunia akan tetap suci, atau perlahan jatuh ke dalam dosa?**

---

## 🌟 Fitur
- 🌱 **Simulasi etika dan moral berbasis teks**  
- 🎭 **Pilihan berdampak pada narasi akhir**
- 🔄 **Cerita ditulis dalam format JSON yang mudah dikembangkan**  
- 🔀 **Randomisasi skenario untuk replayability**  
- 💬 **Kutipan filosofis yang mengarahkan keputusan**

---

## 🛠️ Prasyarat

Pastikan kamu memiliki **Python 3.x** dan **pip** yang terinstal di sistem kamu.

- **Python 3.x**: Untuk menjalankan permainan ini
- **pip**: Untuk mengelola dependensi Python

---

## 🚀 Cara Meng-clone dan Menjalankan Permainan

### 1. Meng-clone Repository

Untuk memulai perjalananmu, pertama kamu perlu meng-clone repositori game ini ke komputer kamu. Buka terminal dan jalankan perintah berikut:

```bash
git clone https://github.com/aguswerdhi/there-is-no-sin.git

```
### 2. Menjalankan Permainan

Setelah menginstal dependensi, jalankan permainan dengan perintah berikut di terminal:

```bash
python3 game.py
